# 워커힐 전이 시나리오 설계 (05_scenarios.md)

- 대상: 워커힐 시뮬레이션 28인 가상 패널 + 희소 페르소나 보강 표본
- 공통 규칙: paired / package-held / one-element / 구간(오픈기·피크기·막기) 라벨링 → 스키마는 04_surveysheet.csv
- 가격 표기: [하얏트 앵커] = 01_sku_master.md 실측값. 워커힐 공식가 확정 시 치환 후 설문지 반영
- 측정 단위: SKU 선택율(비보유자만) + 부대지출 Δ(식음·액티비티, 전 패널) + WTP

---

## S-01 가격: 아이스링크 이용권 조기예약 할인

| 항목 | 기준안(A) | 변경안(B) |
|---|---|---|
| 변경 요소 | 가격 (그 외 전부 고정) | |
| 가격 | 58,000 [하얏트 2025-26 정가 앵커 · 워커힐 치환] | 52,200 (10% 조기예약 할인) |
| 구매 조건 | 시즌 중 자유 구매 | 오픈 동시 사전예약 |
| 응답 대상 | 비보유 패널만 (보유자는 가격 미노출 — package-held) | |

- 근거: 네이버 사전예약 10% = 52,200 주중 한정 [C07·C13·C21], 호텔 케이크 얼리버드 10~15% 관행 [C01·C02·C03]
- 가설: 조기 할인은 오픈기 예약 점유율을 올리고 피크기 정가 수요 일부를 선회(cannibalization) — 구간별 Δ 분리 측정으로 확인
- 판독: 오픈기 선택의사 Δ↑ + 피크기 Δ ≈ 0 → 사전예약 채널 가치 확정 / 피크기 Δ도 음수 → 단순 가격민감형, 상시 할인 설계 필요

## S-02 구성: 이용권 일체형 → 입장권+대여 분리

| 항목 | 기준안(A) | 변경안(B) |
|---|---|---|
| 변경 요소 | 구성 (가격 총액·기간·시간·장소 고정) | |
| 구성 | 이용권 일체형 58,000 (입장+대여 묶음) | 입장권 20,000 + 스케이트 대여 20,000 분리 과금 |
| 응답 대상 | 비보유 패널만 (보유자는 이용권 포함 구조라 제외) | |

- 근거: 투숙객 대여료만 20,000 결제 사례 [E3], 커플 1인 스케이트+1인 입장 조합 [E2·C11], 구성 인지 부족으로 과결제 후회 서술 [E3]
- 가설: 분리형은 비스케이터 동반자 진입장벽 하락 → 입장 인원·링크 카페 식음 Δ↑, 대여 매수 Δ↓
- 판독: ancillary_food Δ↑ & ancillary_activity(대여) Δ↓ 조합 → 묶음 해체가 총매출 중립 + 유입 증가 효과. 선택율 Δ가 음수면 일체형 유지

## S-03 판매시간: 풀사이드 BBQ 운영시간 확장

| 항목 | 기준안(A) | 변경안(B) |
|---|---|---|
| 변경 요소 | 판매시간 (기간·가격·구성 고정) | |
| 운영시간 | 수~일 19:00-21:30 [하얏트 앵커 · E8·C19] | 18:00-22:00 (2.5h → 4h) |
| 기간·가격 | 07-19~08-15 · 성인 178,000 앵커 고정 | 동일 |
| 응답 대상 | 비보유 패널 선택의사 + 시간대별 WTP / 보유자(패키지 포함형)는 부대 음료 지출만 | |

- 근거: 하얏트 풀 18:00 종료 → BBQ 전환 구조 [C10], 성수기 최대 178석·주말 조기 마감 [C19]
- 가설: 시간 확장은 동일 좌석 수요를 타임 분산 + 저녁 이전 가족 수요 흡수 → 마감 손실(지원 못한 수요) 회수, 회전율 감소 trade-off
- 판독: 조기(18시)/후기(21:30 후) 시간대 WTP 분포가 확장 시간대의 한계수요를 직접 추정
